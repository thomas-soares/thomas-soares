# Thomas Soares

**Desenvolvedor Front-End Sênior** com foco em **React.js**, **Next.js**, **TypeScript**, arquitetura front-end e aplicações web de alta performance.

Tenho mais de **12 anos de experiência em desenvolvimento front-end**, atuando em aplicações críticas de negócio nos setores financeiro, óleo e gás, farmacêutico e varejista.

Minha principal experiência está na construção e modernização de aplicações web escaláveis, definição de arquiteturas front-end, criação de design systems, integração com APIs, otimização de performance e promoção da qualidade de código em equipes de engenharia.

- Modernização de aplicações legadas e críticas com React, Next.js, Angular e TypeScript
- Definição de arquiteturas front-end escaláveis para aplicações de grande porte e multi-tenant
- Construção de bibliotecas de componentes reutilizáveis e design systems com Storybook e Figma
- Integração de aplicações front-end com APIs REST, GraphQL, Node.js, NestJS e serviços .NET
- Melhoria de performance, confiabilidade e manutenibilidade por meio de Web Core Vitals, testes automatizados, revisão de código e CI/CD
